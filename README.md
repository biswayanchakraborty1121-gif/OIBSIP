# Number Guessing Game

A console-based Number Guessing Game developed using Java as part of the Oasis Infobyte Java Development Internship.

## About the Project

The computer generates a random number, and the player must guess it within a limited number of attempts.

The game provides hints such as "Too High" and "Too Low" to help the player find the correct number.

## Features

-> Random number generation
-> Three difficulty levels
-> Limited attempts
-> Too High and Too Low hints
-> Win and Lose messages
-> Play Again option
-> Score history across multiple rounds
-> Input validation

## Difficulty Levels

| Level | Number Range | Maximum Attempts |

| Easy  |     1–50     |        10        |
| Medium|     1–100    |         7        |
| Hard  |     1–200    |         5        |

## Technologies Used

-> Java
-> Scanner
-> Random
-> ArrayList
-> Loops and Conditional Statements
-> Switch Case

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   javac NumberGuessingGame.java

5. Run the program:

   java NumberGuessingGame
